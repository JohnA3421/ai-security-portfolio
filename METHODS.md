# Methods, contribution, and evidence handling

John Austin directs this AI-assisted portfolio. AI agents performed much of the implementation,
test execution, evidence inspection, and drafting. The author's role is defining scope, asking
research questions, and reviewing the results with AI assistance. The repository does not imply
that all code or analysis was produced manually.

Experiments use pinned versions, synthetic local fixtures, allowed and disallowed control cases,
recorded observations, source-level comparison where applicable, and explicit limitations.

All review and repeat execution so far occurred within the author's own machine/agent workflow.
An additional agent's skeptical review is not independent external reproduction. No new finding
in this public portfolio has been claimed or confirmed.

The original packet remains unchanged. Before export, immutable Stage-1 files and all 20 entries
of the Stage-2 manifest were checked against their stored SHA-256 hashes. The living roadmap's
known post-seal change was excluded from the Stage-1 integrity check. The roadmap itself is not
published because it also references private work.

Selected JSON records have personal local paths replaced with placeholders and have been
reserialized. Public hashes consequently differ from originals. PROVENANCE.json records both.
The public SHA256SUMS covers this exported package; it establishes file integrity, not vendor
validation, historical timestamp authority, or independent reproduction.

Run the reproduction in a fresh checkout or working copy because it writes new evidence files.
This portfolio preserves prior results, rather than replacing them with reruns performed solely
for presentation.
